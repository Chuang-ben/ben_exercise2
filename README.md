# 气象站坐标系统比较分析 (CRS Comparison)

## 项目概述
分析台湾自动气象站API (O-A0003-001) 中每个测站的两种坐标系统差异：
- TWD67 坐标系统
- WGS84 坐标系统

## 目标
1. 将两种坐标都当作 WGS84 (EPSG:4326) 处理
2. 在同一张图上绘制两种坐标位置
3. 统计每个测站两种坐标之间的距离差异

## 数据来源
- API ID: O-A0003-001 (自动气象站-气象观测资料)
- 坐标系统：TWD67 和 WGS84

## 文件说明
- `crs_analysis.py` - 主要分析脚本
- `requirements.txt` - 依赖包列表
- `data/` - 数据文件夹
- `output/` - 输出结果文件夹
