# 氣象站座標系統比較分析 (CRS Comparison)

## 專案概述
分析台灣自動氣象站API (O-A0003-001) 中每個測站的兩種座標系統差異：
- TWD67 座標系統
- WGS84 座標系統

## 目標
1. 將兩種座標都當作 WGS84 (EPSG:4326) 處理
2. 在同一張圖上繪製兩種座標位置
3. 統計每個測站的不同測站大約差距多遠

## 資料來源
- API ID: O-A0003-001 (自動氣象站-氣象觀測資料)
- 座標系統：TWD67 和 WGS84

## 檔案說明
- `crs_analysis.py` - 主要分析腳本
- `requirements.txt` - 依賴套件列表
- `data/` - 資料資料夾
- `output/` - 輸出結果資料夾
